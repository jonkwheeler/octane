# Upstream React Spring

This package ports the stable React Spring web binding to Octane.

- Repository: https://github.com/pmndrs/react-spring
- Tag: `v10.1.2`
- Commit: `59b1e5306402d3039120e2da464b66e10b1a1aa1`
- License: MIT

Adapted files retain their upstream source path in a header comment. Pure
scheduling is reused from the exact `@react-spring/rafz@10.1.2` package.
React-bound hooks, contexts, animated hosts, and Parallax components are
re-authored against Octane's public runtime.
