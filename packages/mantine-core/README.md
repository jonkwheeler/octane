# @octanejs/mantine-core

Mantine core components for the Octane renderer, ported from
`@mantine/core@9.5.0`.

```ts
import { Button, MantineProvider } from '@octanejs/mantine-core';
import '@octanejs/mantine-core/styles.css';
```

The component API and CSS class contract track upstream Mantine. Components
render through Octane and use `@octanejs/mantine-hooks` and
`@octanejs/floating-ui`.
