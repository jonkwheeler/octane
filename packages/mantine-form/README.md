# @octanejs/mantine-form

Mantine form management for Octane, ported from `@mantine/form@9.5.0`.

```ts
import { useForm } from '@octanejs/mantine-form';
```

The public form, field, validation, list, action, and provider APIs track
upstream Mantine. Hooks use Octane lifecycle and state primitives, and input
handlers receive native browser events.
